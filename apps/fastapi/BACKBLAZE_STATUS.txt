HOW PHOTOS ARE ADDED:
====================

1. SIDEBAR ICONS (Auto-Upload on App Startup):
   - App starts → icon_auto_uploader.py runs
   - Reads 5 PNGs from: apps/web/public/assets/icons/
   - Uploads to Backblaze: sidebar-icons/<name>.png
   - No manual action needed

2. USER UPLOADS (Homework, Notices, etc):
   - User selects file → POST to API
   - Router calls: storage = get_storage_service()
   - Stores in Backblaze under: homework/, notices/, etc
   - Returns download URL

STORAGE ARCHITECTURE:
====================

blob_storage_factory.py (entry point)
         │
         ├─→ if STORAGE_PROVIDER == "backblaze"
         │    └─→ backblaze_blob_service.py
         │         └─→ B2 SDK API
         │
         └─→ else (default: "azure")
              └─→ azure_blob_service.py
                  └─→ Azure API
