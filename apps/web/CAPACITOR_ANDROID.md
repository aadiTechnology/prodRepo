# Android deployment (Capacitor)

This guide covers building and running **Preschool ERP** (`com.aaditech.preschool`) as a native Android app from the React web project in `apps/web`.

## Prerequisites

- Node.js 18+
- [Android Studio](https://developer.android.com/studio) with Android SDK
- JDK 17 (bundled with recent Android Studio)
- `ANDROID_HOME` / `ANDROID_SDK_ROOT` configured (Android Studio usually sets this)

## Project layout

| Path | Purpose |
|------|---------|
| `capacitor.config.ts` | App ID, name, web dir, splash/status-bar plugins |
| `scripts/ensure-android-microphone-permission.mjs` | Declares `RECORD_AUDIO` in AndroidManifest after sync (voice chat) |
| `.env.production` | Production API URL baked into release builds |
| `.env.capacitor` | Emulator dev build pointing at host FastAPI (`10.0.2.2`) |
| `resources/` | Source icon/splash PNGs for `@capacitor/assets` |
| `android/` | Native Android project (regenerate with `npx cap add android`) |

## Build & run commands

All commands run from `apps/web`:

```bash
# 1. Install dependencies (first time)
npm install

# 2. Production build + sync web assets into Android project
npm run cap:build

# 3. Open Android Studio
npm run cap:open:android
```

Then in Android Studio: **Run** on an emulator or connected device.

### Shortcut (build + sync + open)

```bash
npm run cap:android
```

### Local FastAPI on Android emulator

```bash
# Build with .env.capacitor (API at http://10.0.2.2:8022)
npm run cap:build:dev
npm run cap:open:android
```

Ensure FastAPI is listening on `0.0.0.0:8022` (not only `127.0.0.1`) so the emulator can reach it.

### Physical device + local FastAPI

Set your machine's LAN IP in a local env file, then rebuild:

```bash
# .env.capacitor.local (gitignored via *.local)
VITE_API_BASE_URL=http://192.168.1.100:8022
```

```bash
npm run build:capacitor:dev
npm run cap:sync
```

Add your LAN IP to `android/app/src/main/res/xml/network_security_config.xml` if using HTTP.

### Regenerate icons & splash

Replace PNGs in `resources/`, then:

```bash
npm run cap:assets
```

### After web code changes

```bash
npm run cap:build      # production
# or
npm run cap:build:dev  # emulator dev API
```

You only need `npm run cap:sync` if you changed Capacitor plugins or `capacitor.config.ts`.

`npm run cap:sync` also runs `cap:permissions:android`, which ensures
`<uses-permission android:name="android.permission.RECORD_AUDIO" />` is present in
`android/app/src/main/AndroidManifest.xml` (needed for voice chat on Android; the
native project is gitignored).

## React Router

`BrowserRouter` works in Capacitor because the WebView serves the SPA from `https://localhost`. No hash-based routing is required.

Requirements already applied:

- Vite `base: "./"` so asset paths resolve in the WebView
- Relative script/link tags in the production `dist/index.html`

## API / backend notes

1. **Production builds** use `VITE_API_BASE_URL` from `.env.production` (HTTPS).
2. **Hardcoded localhost URLs** were removed from the web app; all HTTP clients use `apiBaseUrl` from `src/config/env.ts`.
3. **FastAPI CORS** includes Capacitor WebView origins (`https://localhost`, `capacitor://localhost`). If you override `CORS_ORIGINS` in `.env`, add those values.
4. **Cleartext HTTP** is allowed only for `localhost`, `127.0.0.1`, and `10.0.2.2` via `network_security_config.xml` (for local dev).

## Known considerations

- **Tenant host login**: Capacitor WebView hostname is `localhost`, so URL-based tenant auto-resolve is skipped (same as local web dev). Users pick their school manually on login.
- **Large bundle size**: The web app is ~2 MB minified; first launch may be slow on low-end devices. Consider further code-splitting later.
- **File downloads / PDF / share**: Features using browser APIs (`navigator.share`, print dialogs) behave differently on Android WebView — test fee receipts and exports on device.
- **`android/` folder**: Listed in `.gitignore` because it is regenerated by Capacitor. Commit it if your team prefers tracking the native project; otherwise run `npx cap add android` after clone.

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Blank white screen | Run `npm run cap:build` and confirm `dist/` exists before sync |
| Network error on login | Check `VITE_API_BASE_URL`, device connectivity, and FastAPI CORS |
| CORS error in logcat | Add `https://localhost` to backend `CORS_ORIGINS` |
| API unreachable on emulator | Use `10.0.2.2`, not `localhost`, in env for host machine API |
| Gradle sync fails | Open Android Studio, install suggested SDK packages, use JDK 17 |
